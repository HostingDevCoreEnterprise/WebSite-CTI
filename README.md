# Calculatoare și Tehnologia Informației (CTI) - FMI Unibuc

Acesta este codul sursă pentru platforma informativă dedicată programului de studii **Calculatoare și Tehnologia Informației (CTI)** din cadrul Facultății de Matematică și Informatică, Universitatea din București.

## Structura Proiectului

Proiectul este o aplicație web statică construită cu HTML, CSS și JavaScript, optimizată pentru performanță, SEO și având un design modern (glassmorphism, animații fluide).

- `index.html` - Pagina principală (Acasă)
- `despre.html` - Detalii despre profilul CTI și perspectivele de carieră
- `studenti.html` - Resurse și detalii despre reprezentarea studențească (ASMI, ASUB)
- `curriculum.html` - Planul de învățământ, materiile pe toți anii și catalogul disciplinelor opționale
- `resurse.html` - Linkuri utile (Note, Orare, Secretariat)
- `subdomeniu.html` - Informații privind solicitarea infrastructurii pentru proiecte
- `relocare.html` - Informații referitoare la campus și alte facilități (dacă există)
- `assets/` - Conține resursele statice:
  - `css/style.css` - Fișierul CSS principal cu toate stilurile
  - `js/main.js` - Script-urile pentru animații, interactivitate etc.
  - `img/` - Imaginile, logo-urile și ilustrațiile folosite pe site

## Caracteristici Principale

- **Design Premium**: UI modern, folosind un paletar de culori elegant (Navy, Burgundy, Gold) și tehnici moderne precum `backdrop-filter`.
- **Responsive**: Aspect adaptat complet pentru telefoane, tablete și desktop-uri.
- **Optimizat SEO**: Integrare de meta tag-uri OpenGraph și meta descriptions pentru a facilita indexarea în motoarele de căutare.
- **Ușor de menținut**: O structură modularizată a stilurilor și fără necesitatea construirii codului (Vanilla web dev).

## Cum pot contribui?

1. Fă fork acestui repository (dacă este găzduit pe GitHub).
2. Clonează proiectul local: `git clone <link-repo>`.
3. Deschide un fișier `.html` direct în browser pentru a vedea site-ul.
4. Adaugă modificările necesare.
5. Creează un Pull Request cu o descriere detaliată a modificărilor.
